# PIKA Billing — מערכת חיובים וחשבוניות

מערכת ווב של **ג.ד. פיקה הולדינגס בע"מ** (ח.פ 515980514) להפקת חשבוניות מס/קבלה
ללקוחות הסלולר (סימים לעובדים) ושליחת המסמך אליהם בהודעה.

מנהל החיובים נכנס מהדפדפן → מוריד טמפלט → מעלה קובץ (שם, טלפון, סכום) →
רואה תצוגה מקדימה עם ולידציה מלאה → מאשר → המערכת מפיקה חשבונית בחשבונית ירוקה
לכל שורה ושולחת ללקוח SMS/וואטסאפ עם הלינק. הרו"ח רואה הכול בחשבונית ירוקה.

## עקרונות מובנים
- **שער בטיחות** — הפקה רק אם חשבון חשבונית ירוקה המחובר הוא ח.פ 515980514.
- **אפס חיוב כפול** — לפני כל ריצה נשלפים מסמכי החודש מחשבונית ירוקה; טלפון
  שכבר קיבל מסמך מדולג. מקור האמת = הספרים, לא קובץ מקומי.
- **אישור אנושי** — שום מסמך לא מופק בלי מעבר על תצוגה מקדימה ולחיצת אישור.
- ההודעה ללקוח נשלחת רק אחרי שהמסמך הופק בהצלחה.
- כל ריצה מדווחת לטלגרם של דקל.

## משתני סביבה (Render → Environment)
| משתנה | מה |
|---|---|
| `SECRET_KEY` | מפתח סשן של Flask |
| `ADMIN_PASSWORD` / `MANAGER_PASSWORD` | כניסת דקל / מנהל החיובים |
| `SIM_BILLING_GI_KEY` / `SIM_BILLING_GI_SECRET` | API חשבונית ירוקה של ג.ד. פיקה |
| `SEND_CHANNEL` | `dry` (בלי הודעות) / `inforu` (SMS) / `whatsapp` (Green API) |
| `INFORU_USER` / `INFORU_TOKEN` | ספק SMS (אם inforu) |
| `GREEN_API_BOT_INSTANCE_ID` / `GREEN_API_BOT_TOKEN` | וואטסאפ (אם whatsapp) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | דיווח ריצות לדקל |
